# 商业版本发布说明

## 当前候选版本

- 版本：以根目录 `VERSION` 为准
- 发布状态：开发验收通过；真实客户资源验收待完成
- 支持升级路径：仅从上一已发布版本顺序升级

## 已交付能力

组织与钉钉登录、客户/主体与冲突检索、案件工作台、合同与期限、隔离扫描文档、
审批与通知、电子卷宗、公告/任务/请假/报销/会议室、全球办公室和办公室数据范围。

P1 商业候选将追加统一分页/导出、文档 OCR/模板/保留、律师工时账单与收款、
管理后台、目录同步 dry run、集成健康、CI 安全门禁和 100 用户负载证据。

## 升级影响

- 数据库迁移通过 Flyway 自动执行，发布前必须在脱敏副本演练。
- 文档扫描服务是生产强依赖；不可用时新上传失败关闭，已有可用文件不受影响。
- Redis 生产连接要求 ACL 用户、密码和 TLS。
- 具体变更见根目录 `CHANGELOG.md`，已知限制和外部资源见最新研发报告。
