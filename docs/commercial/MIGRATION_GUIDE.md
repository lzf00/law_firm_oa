# 客户初始化、迁移与升级指南

## 初始化

1. 建立唯一组织、双语品牌、办公室、时区和币种。
2. 先以钉钉目录同步 dry run 生成差异，批准办公室/角色映射后再幂等应用。
3. 创建至少两名管理员，验证最后管理员保护。
4. 导入客户/主体、案件和文档元数据；文件通过隔离扫描后才标为可用。

## 数据迁移

每批最多 5,000 行，使用版本化模板和稳定外部 ID。先校验再写入；错误报告包含行号、
稳定错误码和修复提示，不回显敏感正文。迁移前后核对总数、金额、关键关系、文件哈希、
随机样本和权限矩阵。失败批次整体回滚或使用幂等键安全重放。

## 升级

先在脱敏副本执行 Flyway 与兼容性测试；数据库变更遵循 expand/migrate/contract。
滚动发布期间新旧版本均应读取旧字段；删除字段至少延后一版。记录镜像摘要、迁移耗时、
锁等待和回滚点，完成健康、登录、案件、文档、审批和财务冒烟后再放量。
