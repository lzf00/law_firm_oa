# 客户上线验收清单

- [ ] 正式域名、TLS、WAF、网络边界和可信代理头通过检查
- [ ] 正式钉钉应用登录、退出、会话过期和目录同步通过
- [ ] 律师、合伙人、行政、财务、档案、管理员六类角色完成中英文验收
- [ ] 两组织、跨办公室、非案件成员和助理文档下载负向用例通过
- [ ] 文件扫描、预览、版本、OCR、检索、保留、法律留置和删除决策通过
- [ ] 工时、费率、账单、收款、对账和财务报表抽样一致
- [ ] PostgreSQL PITR、对象版本恢复、加密备份和隔离恢复证据通过
- [ ] 监控、告警、值班、事件响应、SLA、DPA 和隐私告知已批准
- [ ] 迁移前后数据量、抽样哈希、权限和回滚演练通过
- [ ] 已知限制、客户待办、负责人和截止日已签字确认

证据必须记录版本、提交 SHA、制品摘要、执行人、UTC 时间和结果。真实钉钉、云资源、
域名和监管决策只能由客户资源到位后签署，不以本地自动化替代。
