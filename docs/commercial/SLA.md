# 服务等级协议（SLA）基线

本基线供商务合同引用，最终数值以客户资源架构和双方签署版本为准。

- 月度可用性目标：99.9%，计划维护提前 3 个工作日通知。
- P1 严重故障：15 分钟确认、1 小时提供遏制方案、持续更新至恢复。
- P2 主要功能受损：30 分钟确认、4 小时提供绕行或修复计划。
- P3 一般缺陷：1 个工作日确认，进入双方约定版本。
- 数据库目标 RPO 15 分钟、RTO 2 小时；文件目标 RPO 1 小时、RTO 4 小时。
- 可用性不含客户网络、钉钉/云厂商不可控故障、获批维护及客户未按要求配置资源。
- 每月提供可用性、事件、备份恢复、容量和安全补丁摘要。

服务抵扣、责任上限、不可抗力和退出协助必须在正式合同中由双方律师确认。
