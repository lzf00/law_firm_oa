# 支持与维护政策

支持时间：工作日 09:00–18:00（客户当地时间）；P1 事件提供 7×24 紧急渠道。

提交工单应包含租户、时间、用户角色、关联 ID、重现步骤和脱敏截图，不得发送密码、
令牌或完整案件文件。支持人员默认看不到文档正文；临时诊断访问必须经客户授权、
限时、可撤销并完整审计。

版本政策：

- 每月维护版本，紧急安全修复按风险随时发布；
- 当前主版本和前一主版本提供支持；
- 高危依赖在确认可利用性后优先修复；
- 破坏性迁移提前至少一个版本通知并提供演练与回滚说明。

客户负责域名、证书、钉钉应用、云账号和合法数据使用；服务方负责应用缺陷、发布包、
运维手册和约定范围内的技术支持。
