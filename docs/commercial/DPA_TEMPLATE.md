# 数据处理协议（DPA）要点模板

1. 律所为数据控制者/个人信息处理者，OA 服务方为受托处理方，仅按书面指示处理。
2. 附件列明处理目的、数据类型、主体、期限、地区和批准的分处理者。
3. 人员承担保密义务；执行最小权限、强认证、加密、日志、漏洞修复和隔离备份。
4. 新增分处理者提前通知，律所有合理异议权；分处理者承担同等义务。
5. 安全事件在发现后无不当延迟通知，提供影响、措施和持续更新，不擅自对外确认责任。
6. 协助数据权利请求、影响评估、监管问询和审计；费用与边界由正式合同约定。
7. 服务结束后按指示返还或安全删除，法律强制保留部分隔离并限制处理。
8. 跨境处理须有适用机制、补充措施和地区清单，未经批准不得改变存储区域。
9. 审计优先采用独立报告、配置证据和受控远程审查，避免暴露其他客户信息。

本文件是产品交付模板，不替代双方针对适用法域签署的法律文件。
