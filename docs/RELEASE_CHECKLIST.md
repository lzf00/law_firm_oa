# 发布、迁移与回滚检查表

每次发布复制本文件生成版本化验收记录，所有证据需注明执行人、UTC 时间、提交 SHA
和制品摘要。任何 P0 项失败都不得继续生产发布。

## 1. 发布元数据

- [ ] `VERSION`、`CHANGELOG.md`、Git tag 和镜像 tag 一致
- [ ] 发布提交已通过评审，工作区干净
- [ ] 后端、前端、API 冒烟、浏览器 E2E、生产配置检查全部通过
- [ ] SBOM、依赖/镜像漏洞、许可证和密钥扫描结果已归档
- [ ] 数据库、对象存储和 Redis 备份已完成且校验和有效

## 2. 数据库迁移

- [ ] 在生产数据脱敏副本上执行全部 Flyway 迁移
- [ ] 记录迁移前后 schema version、耗时、锁等待和数据量
- [ ] 验证新旧应用版本的兼容窗口与滚动发布顺序
- [ ] 对新增非空字段、索引和回填任务设置明确的超时与终止条件
- [ ] 隔离恢复环境完成备份恢复和关键业务抽查

## 3. 配置与资源

- [ ] `APP_ORGANIZATION_ID` 指向本客户唯一组织 UUID
- [ ] 域名、TLS 证书、钉钉回调地址和 CORS 来源已确认
- [ ] 数据库、Redis、对象存储、杀毒和外部集成凭证来自密钥管理服务
- [ ] 生产环境关闭开发登录，Cookie Secure 属性已开启
- [ ] 告警接收人、支持窗口、RPO/RTO 和升级联系人已确认

## 4. 发布验证

- [ ] 健康与就绪探针正常，数据库连接池和后台任务无异常
- [ ] 律师、合伙人、行政、财务、档案和管理员角色完成中英文关键路径抽查
- [ ] 钉钉登录、退出和会话过期行为正常
- [ ] 两组织隔离、办公室隔离、案件授权和文档权限负向用例通过
- [ ] 上传、扫描、预览、下载、审批、通知和审计链路完整

## 5. 回滚

- [ ] 明确可回滚的上一版本镜像摘要和配置版本
- [ ] 数据库迁移已分类为可逆或前向修复；不可逆迁移有恢复方案
- [ ] 回滚触发阈值、决策人、执行人和最长决策时间已确认
- [ ] 回滚后重新运行健康、登录、案件、文档和审批冒烟测试
- [ ] 回滚事件、影响范围、数据一致性检查和后续修复已记录
