## 3. 本轮测试发现并修复的问题

1. 开发认证过滤器在缺少 `X-Dev-User` 时默认授予管理员身份。
2. 前端 Nginx 为所有 `/api/*` 请求固定注入管理员身份，绕过登录页。
3. 登录页初始化阶段提前请求受保护的 `/api/me`，造成预期 403 和控制台噪声。
4. 英文界面收到的部分后端业务错误仍是中文。
5. 全所管理员跨办公室指派案件/任务时被错误要求属于目标办公室。
6. 审批办公室解析误把合同当作直接持有 `matter_id`，与实际多对多表不一致。
7. 开发身份统一携带 `ROLE_ADMIN`，虽然数据库权限仍有效，但会向前端暴露误导性角色。

现在开发演示身份只在用户点击“进入本地演示环境”后，由前端显式发送；匿名直连后端
或通过 Nginx 访问均被拒绝。`/api/me` 只在进入业务页面后加载，后端稳定错误码可按
请求语言返回中英文消息。

8. 导出状态查询在只读事务内写下载审计，导致 PostgreSQL 拒绝写入。
9. 跨办公室案件成员被办公室编制校验阻止登记工时。
10. `size=101` 参数约束异常被误映射为 HTTP 500。
11. 品牌辅助文字和滚动表格不满足 WCAG AA。
12. 前端 Nginx 镜像仍以 root 身份运行。

上述问题均已修复并经过对应 API、浏览器、负载或安全扫描回归。

## 4. 后续持续改进

### 客户资源验收

1. 使用真实钉钉企业应用完成授权、回调、会话过期和组织同步验收。
2. 在生产托管环境演练 PITR、对象版本恢复和密钥轮换。
3. 完成电子签章、邮件、日历、发票/会计系统的提供商验收。
4. 由合伙人、财务和合规确认费率、保留期、审批链与跨境规则。

### 工程质量持续提升

1. 优先补齐 `DocumentService`、`WorkflowService`、`MatterService`、`OfficeAccessService` 和
   组织同步服务的成功/失败/并发单元测试。
2. 为 Controller 增加 MockMvc 契约测试，校验 HTTP 状态、稳定错误码和中英文消息。
3. 引入 Testcontainers 集成测试，独立创建 PostgreSQL/Redis/MinIO 测试环境，避免
   测试依赖开发数据。
4. 覆盖率门槛分阶段提升：先要求新增/变更代码 70%，再逐步提高高风险包的分支覆盖。

### 后续产品深化

1. 流程名称、通知模板、审计动作和邮件内容全部双语化。
2. 日期按用户/办公室时区展示，金额按案件币种格式化，并记录汇率来源和折算日期。
3. 增加可视化合同版本比较、动态水印、外发审批和到期归档策略。
4. 增加客户门户、知识库和跨办公室经营分析。
