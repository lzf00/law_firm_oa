## 审计口径

本台账覆盖左侧导航的 19 个业务入口，同时检查页面主路径、后端能力、权限边界、双语、移动端与可验收性。状态含义：

- `验收通过`：前后端主链路、权限正反例和浏览器交互均已纳入当前发布验收。
- `管理完成`：管理员可在界面完成配置，后端有实时权限校验、风险提示与审计。

“后续增强”均为下一商业阶段的产品深化，不构成本次 100 人试点的上线阻断项。

## 管理后台权限模型

管理员后台采用“用户 - 角色 - 权限 - 办公室范围”四层模型：

1. 用户层：启用/停用、角色分配、临时访问截止时间；停用账号下一请求即失效。
2. 角色层：集中维护权限集合并预览新增、移除及受影响人数；保存后立即影响后端授权。
3. 权限层：实时聚合最终权限及来源角色；前端只负责降低误操作，后端逐请求重新判断。
4. 数据范围层：按办公室控制可见数据，并显示主办公室、访问级别、有效期和活动状态。
5. 风险层：提示无角色、无有效办公室、已过期、7 天内到期和非活动账号。

关键管理权限：

| 权限 | 用途 |
|---|---|
| `ADMIN_CONSOLE_VIEW` | 查看管理控制台 |
| `USER_ACCESS_MANAGE` | 管理账号状态、角色与办公室范围 |
| `ROLE_PERMISSION_MANAGE` | 调整角色权限 |
| `SETTINGS_MANAGE` | 管理组织级系统设置 |
| `WORKFLOW_RULE_MANAGE` | 管理工作流规则 |
| `AUDIT_VIEW` | 查看安全审计日志 |
