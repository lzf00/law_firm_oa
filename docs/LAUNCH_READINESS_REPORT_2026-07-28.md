# 律师行业 OA 上线准备报告

日期：2026-07-28  
适用范围：100 人以内律师事务所，中英双语，低并发、合同与案件文件为核心数据

## 1. 结论

当前结论：**本地发布候选版本有条件通过（Conditional Go）**。

代码、容器构建、正式配置防误用、数据库迁移、权限边界、文件安全、备份恢复和主要
业务流程均已通过本地自动化验收。当前不能直接宣称生产上线完成，因为钉钉正式应用、
正式域名与 TLS、托管数据服务、生产监控、真实数据迁移和用户验收属于外部环境工作，
本轮没有也不应使用占位配置代替验证。

## 2. 本轮安全与上线改进

- 增加生产配置启动校验：拒绝开发登录、占位值、本地地址、非 HTTPS 回调/浏览器
  对象存储地址和非 PostgreSQL 数据库；配置不安全时应用拒绝启动。
- Redis 会话键由原始 bearer token 改为 SHA-256 摘要，降低 Redis 键泄漏风险。
- 生产 Nginx 增加 HSTS、CSP、X-Frame-Options、MIME 嗅探保护、Referrer-Policy
  与 Permissions-Policy。
- 生产入口仅暴露 readiness/liveness；其他 Actuator 路径统一返回 404。
- 后端和前端运行镜像执行 Alpine 安全更新，前端 Nginx 固定为
  `1.30.4-alpine3.24`。
- 修复依赖扫描发现的问题：MinIO Java 8.6.0、Vitest 3.2.6、Jackson 2.21.5、
  Netty 4.1.136.Final、Commons Lang 3.18.0；补充 MinIO 8.6.0 所需的
  `okhttp-jvm` 5.1.0。
- 删除未被应用使用、容易产生错误安全感的 `JWT_SECRET` 配置。
- 新增隔离式生产就绪脚本，演练干净数据库迁移、无演示数据、开发身份头禁用及
  占位配置 fail-closed。

- 钉钉登录接口、会话、组织同步和外部身份映射。
- 全球办公室、时区、币种、跨办公室案件协作和数据范围隔离。
- 客户/主体、利益冲突检索、案件立案、成员、合同、期限、电子卷宗。
- 私有对象直传、摘要校验、文件类型限制、下载授权、突发下载告警和硬限流。
- 公告、任务、评论、通知、统一待办、请假、报销、会议室和用印。
- 案件与合同多级审批、驳回状态回写、审批权限边界。
- 通讯录、部门统计、审计检索和中英双语界面。
- PostgreSQL 与对象文件本地备份、摘要校验及隔离恢复演练。

## 5. 正式上线前必须完成

| 优先级 | 工作项 | 放行证据 |
|---|---|---|
| P0 | 钉钉正式应用配置 | 真机登录、回调、组织同步、离职/禁用账号实测 |
| P0 | 域名、TLS、WAF/负载均衡 | HTTPS 扫描、可信代理头、限流和安全组检查 |
| P0 | PostgreSQL 生产保护 | TLS、HA、PITR、备份告警和一次隔离恢复报告 |
| P0 | 对象存储生产保护 | 私有桶、加密、版本、CORS、生命周期、跨账号/区域副本 |
| P0 | 密钥管理 | 数据库、Redis、对象存储和钉钉密钥入库并完成轮换 |
| P0 | 监控告警 | 5xx、延迟、资源、备份、Outbox、登录和下载异常测试告警 |
| P1 | 数据与权限验收 | 5–10 名试点用户、真实样例案件、最小权限抽查 |
| P1 | 发布与回滚 | 镜像版本固化、旧版本回滚、数据库向前兼容演练 |
| P1 | 制度与合规 | 日志/卷宗保留期、导出、删除、离职交接和审计责任人确认 |

## 6. 推荐上线顺序

1. 建立生产基础设施和密钥，不导入真实文件。
2. 部署候选镜像，运行生产就绪检查和基础监控测试。
3. 接入钉钉正式应用，导入 5–10 名试点用户。
4. 用脱敏案件完成登录、上传、下载、审批、审计和恢复验收。
5. 试运行一周，处理告警与权限反馈。
6. 完成上线评审后同步 100 人组织，分批迁移真实资料。

## 7. 风险说明

- 本地 MinIO 及其 `9001` 控制台仅用于开发，不能作为生产公网文件入口；生产应采用
  受支持的私有 S3 兼容对象存储。
- 本地 Compose 的 PostgreSQL、Redis 和 MinIO 没有代表云上 HA、TLS、PITR 或
  跨区域复制已经完成。
- 钉钉代码路径和模拟测试通过不等于正式 OAuth 已验证；正式 Client ID、Secret 和
  回调地址必须在真实企业应用上闭环。
- 本报告不包含真实生产部署、真实用户消息发送或真实律师文件迁移。

详细操作见 `docs/PRODUCTION_OPERATIONS.md`；测试覆盖见 `docs/TEST_MATRIX.md`。
