# 数据权利申请与投诉处理流程

1. 统一渠道收件并生成编号，不在普通群聊传递身份证明或案件材料。
2. 两个工作日内确认收件；由隐私负责人验证申请人身份和代理权限。
3. 搜索 OA、对象存储、备份和已批准集成，标记案件保密、诉讼保存和第三方权利冲突。
4. 业务负责人和承办合伙人决定查阅、更正、导出、限制或删除范围；删除必须通过系统
   法律保留检查并保留不可篡改的决定审计。
5. 在适用法定期限内回复。无法满足时说明依据、救济和投诉渠道。
6. 关闭前记录实际交付、例外、审批人、日期和证据，不把交付文件长期留在工单附件。

最低工单字段：申请编号、数据主体、请求类型、身份验证、涉及案件、司法辖区、法定
截止日、法律保留、处理决定、审批人、交付方式、关闭时间。

投诉升级：一般投诉由隐私负责人处理；疑似泄露或未授权访问立即转入
`INCIDENT_RESPONSE.md`；重大或跨境事项通知管理合伙人和外部法律顾问。
