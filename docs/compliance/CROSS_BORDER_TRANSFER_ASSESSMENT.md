# 跨境数据处理决策模板

每个境外办公室、境外云区域、跨境协作者或境外供应商单独填写。

- 业务场景与必要性：
- 数据出口方/进口方：
- 涉及司法辖区：
- 数据主体和规模：
- 数据类型及敏感程度：
- 存储位置、远程访问位置和备份位置：
- 处理目的、频率和期限：
- 可否通过本地处理、脱敏或最小字段替代：
- 适用传输机制、合同条款和监管程序：
- 政府访问、再转移和供应商风险：
- 加密、密钥控制、访问审批、日志和删除措施：
- 数据主体告知/单独同意要求：
- 批准人、批准日、复核日：

任一项未明确、供应商无法承诺删除/审计、或高敏感案件超出既定区域时，系统集成保持
关闭；不得仅以“云服务通用条款”替代逐项评估。
