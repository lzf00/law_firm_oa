# 律师事务所 OA

面向 100 人以内律师团队的模块化单体 OA，已覆盖组织与钉钉免登、主体/客户、冲突
检索、案件、合同、期限、私有文档、Flowable 审批、用印和电子卷宗。后端采用类似
飞书审批中心的统一待办模型，并补齐业务状态回写、站内通知、催办/转交、审计检索、
幂等请求、Outbox 可靠任务和多来源通讯录快照同步。第二阶段已加入公告与已读回执、
内部协作任务、请假审批、费用报销、会议室预约和组织通讯录。
第三阶段面向文森律师事务所的国际业务场景，加入全局中英文切换、可配置双语品牌、
12 个全球办公室、人员主办公室，以及案件的司法辖区、工作语言、时区和结算币种。
第四阶段加入办公室级数据范围：普通成员只看到已授权办公室的通讯录、公告、会议室、
协作任务、请假和报销；办公室管理员只管理被授权办公室；全所管理员可跨办公室；
案件成员和被明确指派的协作者仍可跨办公室访问相关业务。
第五阶段补齐分所成员管理、临时授权有效期、授权变更审计，以及文档下载突发预警、
硬限流和安全事件查询；同时提供本地数据库与 MinIO 备份、校验和隔离恢复演练脚本。

## 技术栈

- Java 21、Spring Boot 3.5、Flowable 7
- PostgreSQL 16、Redis 7、MinIO
- Vue 3、TypeScript、Vite、Element Plus
- Docker Compose 统一开发与验证环境

## 本地启动

```bash
cp .env.example .env
docker compose up --build
```

启动后：

- OA 登录页：http://localhost:18080/login
- OA 首页：http://localhost:18080（未登录时自动跳转登录页）
- 后端健康检查：http://localhost:8081/actuator/health
- MinIO 管理控制台：http://localhost:9001（仅供开发/运维查看私有文件桶，不是 OA 页面）

开发环境登录页会显示“进入本地演示环境”，进入后使用模拟管理员身份。生产环境禁止
该机制，只显示钉钉 SSO 登录；钉钉授权地址和一次性 `state` 由后端生成，`Client
Secret` 不会进入浏览器。

## 企业级后端能力

- 统一审批中心：待办、已办、审批动作记录、通过、驳回、转交和催办。
- 一致性：同一业务只允许一个运行中流程，审批结束后事务性回写业务状态。
- 幂等：发起审批、完成任务和转交任务支持 `Idempotency-Key`，同键异参返回 409。
- 可靠通知：业务事务写 Outbox，后台任务使用指数退避重试，8 次后进入 `DEAD`。
- 通讯录：支持钉钉、飞书和手工快照的外部身份映射；业务权限只依赖本地快照。
- 期限任务：后台自动标记逾期，按 `reminder_policy.daysBefore` 生成去重提醒。
- 文档完整性：上传完成时流式计算 SHA-256，摘要或大小不一致的会话固化为失败。
- 可观测性：响应携带 `X-Correlation-Id`，操作审计记录来源 IP、User-Agent 和关联 ID。
- 门户与协作：公告发布后可靠通知，任务按负责人/参与人隔离并保留评论和状态。
- 行政审批：请假与报销共用统一审批中心，完成后事务性回写并通知申请人。
- 资源预约：会议室容量校验，PostgreSQL 排他约束阻止并发重叠预约。
- 国际化组织：双语租户品牌、全球办公室、人员主办公室、当地时区与默认币种。
- 办公室权限：角色权限与数据范围分离，支持成员、办公室管理员、全所管理员三级范围。
- 授权管理：支持分所成员加入、主办公室调整、管理员权限、临时授权到期和变更历史。
- 下载风控：单用户 5 分钟第 10 次下载预警，达到 30 次后返回 429 并保留安全事件。
- 跨办公室协作：案件成员、任务负责人/参与人、审批受让人采用显式授权，不因办公室隔离失效。
- 跨境案件：记录承办办公室、国家、司法辖区、中文/英文/阿拉伯语工作语言和结算币种。
- 双语门户：登录页、全局导航、业务页标题和全球办公室可即时切换中英文并持久化偏好。

接口约定和新增端点见 [`docs/BACKEND_API.md`](docs/BACKEND_API.md)。

## 安全边界

- 文件对象保持私有，不暴露永久公网 URL。
- 权限由后端按案件/合同成员关系判定，前端隐藏按钮不视为安全控制。
- 生产启动必须提供独立数据库密码、会话签名密钥及钉钉应用凭证。
- 文档下载记录来源 IP、User-Agent、关联 ID；高频下载写入独立安全事件表。
- 所有已实现的敏感写操作和下载地址申请写入审计日志。

```bash
scripts/backup-local.sh
scripts/verify-backup.sh /absolute/path/to/law_firm_oa/backups/<timestamp>
```
